
# 📋 Task Manager
<img width="1344" height="638" alt="Task Manager" src="https://github.com/user-attachments/assets/11e2fc55-97b2-4dff-ac49-abbb1a570036" />

A simple and professional Task Manager web application built using HTML, CSS and JavaScript.

🚀 Live Demo

## ✨ Features

- Add tasks
- Delete tasks
- Complete tasks
- Search tasks
- Filter tasks
- High, Medium and Low priority
- Total task counter
- Pending task counter
- Completed task counter
- LocalStorage
- Responsive design
- Pure black background

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
